# 3.0 Beta Changelog:
## Feature Additions
- Returned/Fixed Singleplayer Functionality!
- Added co-op! New "Invite Friends" button in singleplayer.
- Introducing a new Reputation system for dedicated multiplayer.
- Added Tips in the pause menu.
- Added and fixed lots of Tillage's textures.
- Added randomly generated character roleplay stats in character creation.
- Added tons of new and super detailed structures.
- Added new main menu music.


## Mod Additions- Added Nirvana.
A detailed cannabis mod that focuses on farming and functionality.
- Added Naturalist.
Naturalist adds more real life animals. Compatible with Alex's Mobs and a few more.
- Added Blood Bits.
Fighting now has a little bit of pixel gore.
- Added Amendments.
Extra features and tweaks to many existing vanilla blocks.
- Added Rain should extinguish campfires.
Rain extinguish campfires if outside.
- Added Loot Journal. (Replaced Pickup Notifier)
Shows the player what they recently picked up.
- Added Particular. (Replaced Effective)
Adds particles from splashes, rain and more.
- Added Biomancy.
Flesh-related 'magic' stuff and bio-machines.
- Added Chalk.
Chalk allows you to draw marks for easier navigation in the world.
- Added Lucent.
Dynamic Lighting (Works with Create).
- Added Quark Delight.
An add-on for Farmer's Delight that adds compatibility with Quark.
- Added e4mc.
Adds the ability to share your singleplayer worlds. (Co-op)
- Added Fantasy Armor Medieval Series.
Adds many new netherite-tier detailed and decorational armor sets.
- Added Ribbits.
Meet and trade with Ribbits, little frog-like villagers.
- Added Dynamic Trees - Alex's Mobs Compat.
Adds banana plants and acacia blossoms drops for acacia trees.
- Added Rustic Delight.
Pancakes, coffee, bell peppers and cotton.
- Added Better F3.
Improves the F3 debug screen.
- Added Does It Tick?
Performance mod. Disables entities ticking while not visible.

## Gameplay Changes
- Main Menu Announcements and Versions now read live from Github.
- Changed most of the UI menus.
- Added an animated game intro.
- Put Voice Chat settings into game settings.
- Removed "Quit to Desktop" button.
- Removed origin biome.
- Made realistic clouds more realistic.
- Players no longer spawn with a horse.
- Adjusted some mob spawn rates.
- Changed the starter kit items.
- Made multiplayer-style gamerules global.
- All saplings grow into dynamic trees.
- Nerfed the Fisherman Trap.
